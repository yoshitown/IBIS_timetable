# IBIS2026 タイムライン & アジェンダ Viewer

第29回情報論的学習理論ワークショップ（IBIS2026）のプログラム概要・セッション情報・要旨を統合可視化するインタラクティブWebアプリケーション

---

## 1. 概要

本プロジェクトは、2026年10月26日（月）〜10月29日（木）にソニックシティ（埼玉県さいたま市）で開催される「第29回情報論的学習理論ワークショップ（IBIS2026）」のタイムテーブルおよび発表概要をグラフィカルかつ直感的に閲覧するためのWebアプリケーションです。

チュートリアル、企画セッション、招待講演、ポスターセッション、パネルディスカッションにわたる全プログラム情報を集約し、現在進行中のセッションをリアルタイムで把握できるインタラクティブなタイムラインUIを提供します。

---

## 2. 主な機能

- **タイムライン統合表示 (Interactive Gantt & Schedule View)**
  - 4日間のタイムテーブルをグラフィカルなバーチャートとして一覧表示します。
  - セッション種別（チュートリアル、企画セッション、招待講演、ポスター発表、パネルディスカッションなど）ごとにカラーコード化され、全体の進捗や平行トラックを直感的に把握できます。
- **現在時刻インジケーター（赤線バー / Red Time Line）**
  - 学会開催中の現在時刻に対応する赤い垂直インジケーター線をタイムライン上にリアルタイム表示します。
  - 現在どのセッションが進行中か、次に控えるセッションが何かを瞬時に識別可能です。
- **詳細・要旨モーダル / ドロワー (Session Details & Abstract View)**
  - タイムライン上のセッションブロックをクリックすることで、画面右側にドロワー（またはポップアップモーダル）が開きます。
  - 登壇者情報、所属、講演タイトル、オーガナイザー、要旨（Abstract）などの詳細データを表示します。
- **データ自動取得スクレイパー (Web Scraper & PDF Parser)**
  - IBIS2026公式サイトおよびPDFプログラム概要から最新のプログラム情報を自動抽出し、構造化データ（JSON / CSV）として更新・保存するパイプラインを備えています。

## 3. 技術構成

本アプリケーションは、Pythonを中心としたモダンな軽量データサイエンス＆Web技術スタックで構成されています。

| カテゴリ | 採用技術・ライブラリ | 役割・用途 |
| :--- | :--- | :--- |
| **言語** | Python 3.10+ | バックエンド・データ処理・スクレイピング全般 |
| **Web UI** | Streamlit | ダッシュボード構築・UIコンポーネント管理 |
| **可視化 UI** | Plotly / Custom HTML Component | タイムラインチャート描画、現在時刻線のリアルタイムレンダリング |
| **データ取得** | BeautifulSoup4 / Requests / PyPDF2 | 公式サイトWebスクレイピングおよびPDF解析 |
| **データ処理** | Pandas | タイムスケジュール構造化、日時パース、データフィルタリング |

## 5. セットアップ手順

### 前提条件
- Python 3.10 以上がインストールされていること
- Git が利用可能であること

### 1. リポジトリのクローン
```bash
git clone https://github.com/your-org/ibis2026-timeline-app.git
cd ibis2026-timeline-app
```

### 2. 仮想環境の作成と有効化

**macOS / Linux:**
```bash
python -m venv venv
source venv/bin/activate
```

**Windows:**
```cmd
python -m venv venv
venv\Scripts\activate
```

> **Note (uv を使用する場合)**:
> ```bash
> uv venv
> source .venv/bin/activate
> ```

### 3. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

*(参考) `requirements.txt` の主な内容:*
```text
streamlit>=1.28.0
plotly>=5.18.0
pandas>=2.1.0
requests>=2.31.0
beautifulsoup4>=4.12.0
pypdf>=3.17.0
```

### 4. プログラムデータの事前更新（任意）
最新のWeb/PDF情報からアジェンダデータを再生成する場合は、以下のスクレイパーを実行します。
```bash
python scraper/web_scraper.py
```

### 5. アプリケーションの起動
```bash
streamlit run app.py
```
起動後、ブラウザで `http://localhost:8501` にアクセスしてください。

タイムラインは実際の現在時刻 (JST) を基準に「進行中」を判定し、1分ごとに自動更新されます。
デバッグ・リハーサル用に時刻を固定したい場合は環境変数 `IBIS_DEBUG_NOW`（`YYYY-MM-DD HH:MM` または `HH:MM`）を指定します。
```bash
IBIS_DEBUG_NOW="2026-10-27 11:20" streamlit run app.py
```

## 6. 使い方の詳細

- **日付の切り替え**
  - サイドバーの「日付選択」タブより、10月26日（月）〜10月29日（木）を選択して表示対象のスケジュールを切り替えます。
- **現在時刻追従モードの切り替え**
  - 「現在時刻表示（赤線バー）」をONにすると、リアルタイムの時刻線が表示されます。
  - 会期外（事前・事後）でのテスト用として、仮想の現在日時を指定できるタイムスライダーも提供されています。
- **詳細・要旨の閲覧**
  - 興味のある講演ブロックをクリックすると、右側ドロワーに詳細（スピーカー、所属、要旨）が展開されます。
- **検索・フィルタリング**
  - キーワード検索フォームに登壇者名（例: 「今泉允聡」「Christopher Rackauckas」）や技術キーワード（例: 「Neuro-symbolic」「最適化」）を入力することで、対象セッションを強調表示・抽出可能です。
